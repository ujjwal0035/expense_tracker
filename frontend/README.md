# ExpenseIQ - Frontend

The frontend for ExpenseIQ is a responsive, high-performance React application built with Vite. It features interactive charts, secure CSV drag-and-drop uploads, and real-time background job tracking.

## Tech Stack
- **Framework:** React 19 + Vite
- **Styling:** Tailwind CSS v4
- **Routing:** React Router DOM v7
- **Charts:** Recharts
- **Icons:** Lucide React

## Getting Started

### Prerequisites
- [Node.js](https://nodejs.org/) (v18 or higher recommended)
- npm or yarn

### Installation
1. Navigate to the frontend directory:
   ```bash
   cd frontend
   ```
2. Install the dependencies:
   ```bash
   npm install
   ```

### Running the Development Server
To start the application in development mode:
```bash
npm run dev
```
The application will be accessible at `http://localhost:5173`. Any changes you make will instantly hot-reload the page.

### Building for Production
To build the application for production deployment:
```bash
npm run build
```
The optimized production files will be output to the `dist` directory. You can preview the production build using:
```bash
npm run preview
```
